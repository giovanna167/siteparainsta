=========================================
             PENGUINISMO
=========================================

Mini site para apresentação do projeto
e link da bio do Instagram.


ARQUIVOS
-----------------------------------------

index.html
Página principal do site.

style.css
Estilos, cores, layout e responsividade.

script.js
Interações e configuração dos links.

pinguim.png
Mascote oficial do Penguinismo.


COMO ABRIR
-----------------------------------------

1. Abra a pasta no Visual Studio Code.

2. Verifique se os cinco arquivos estão
   dentro da mesma pasta.

3. Clique com o botão direito em:

   index.html

4. Escolha "Open with Live Server".

Também é possível simplesmente abrir
o arquivo index.html no navegador.


CONFIGURAR OS LINKS
-----------------------------------------

Abra:

script.js


Procure:

const LINK_COMUNIDADE =
"https://seu-link-aqui.com";


Troque pelo endereço verdadeiro
da plataforma.


Depois procure:

const LINK_INSTAGRAM =
"https://instagram.com/seuinstagram";


Troque pelo Instagram oficial
do Penguinismo.


IMAGEM
-----------------------------------------

A imagem do mascote deve se chamar:

pinguim.png

Ela precisa ficar na mesma pasta
do index.html.

-----------------------------------------
